SQL Server

ANORA Vaccination Center
Management System

Database design, business logic and reporting for a network of vaccination centers.

A team project that designs a database for managing vaccination records, appointments and vaccine stock across multiple centers. It covers requirements analysis, use cases and a data model, then a SQL Server implementation with 13 tables, 10 functions, 4 triggers, 2 stored procedures and 2 views. Triggers keep stock levels in sync after each injection and warn about low stock and expiring batches, and a daily job flags upcoming appointments for email reminders. A demand forecast function combines last period's volume, a growth rate, confirmed bookings and a safety buffer to suggest how much vaccine each center should reorder. The report ends with data-entry forms and printable reports.

Tools: SQL Server, Figma
